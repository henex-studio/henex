Section E

Layout Modes

Schematic demonstration of L1 through L4 with placeholder content. L1 is the primary layout for case study sections (D09).

L1 — Section Header + Content
Title column and lead-copy column sit near 1:1 width, side by side, as one header row. The section's real content (cards, image, list) sits BELOW this header row as a separate block — header and content do not run alongside each other. This is the reference-page pattern: kicker+title on the left, lead paragraph on the right, one line, then content underneath.
Kicker + Title
Lead copy, one short paragraph
Content below the header row (cards, image, or list — spans full width)
L2 — Aside + Content
A narrow aside column (kicker/label + heading, e.g. "Overview", "Background") stays beside a wider content column for the FULL HEIGHT of the section — they run side by side, not stacked. This is the current dominant pattern in UX case studies (ux-two-col).

Section G

Spacing Scale

Five-step token scale (D16). Confirmed after a full-site audit found the same "label sits too close to the content below it" problem recurring in 7 places, ranging 0-40px with no shared rule. Replaces ad hoc per-selector values.

The five tokens
--space-xs8px
Icon-to-label, tightest inline gaps, card-to-inner-text top offset.
--space-sm16px
Card-internal title-to-body, meta-label-to-heading.
--space-md24px
Label/kicker-to-grid gap, standard card padding.
--space-lg32px
Sibling-container gap within the same section.
--space-xl48px
Grid-to-CTA gap, grid-to-next-block gap.
Applied example — label, grid, CTA rhythm
Before: 14px label-to-grid, 12px grid-to-CTA (audit finding). After: --space-md then --space-xl.
